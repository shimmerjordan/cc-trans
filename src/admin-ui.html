下面是经本服务转发时,各参数的实际可用性。红色是会直接 400 的坑,灰色是可选项。改动客户端参数下发在「客户端」页。

必填三件套
model max_tokens messages
system 与 tools 可选。stream:true 正常透传,输出超过 ~16K token 建议开。
temperature / top_p / top_k
新家族已移除
Opus 4.7 / 4.8 / 5、Sonnet 5、Fable 5 传了直接 400。老模型(4.6 及更早、Haiku)仍可用。
客户端开「清洗不支持的参数」可自动删掉它们,不必改客户端代码。
thinking
{"type":"adaptive"}
新家族只认 adaptive。Opus 4.7+ / Sonnet 5 也接受 disabled;Fable 5 不接受 disabled(只能省略)。老模型用 enabled + budget_tokens。
output_config.effort
low medium high xhigh max
控制思考深度,直接影响耗时与 token 消耗,默认 high。4.6+ 支持(4.6 无 xhigh);Sonnet 4.5 / Haiku 4.5 不支持。各模型的实际支持情况见上方目录表的 effort 列。
订阅门禁(最容易踩)
system 必须以固定前缀开头
非 Haiku 模型的 system 必须以 You are Claude Code, Anthropic's official CLI for Claude. 开头,而且必须是独立的第一个 block(不是拼进同一段字符串)。不满足时上游返回脱敏的 400/429 "Error"——报错本身看不出原因,很容易误判成限流。
Haiku 豁免。客户端开「自动注入前缀」即可,已有前缀则不改动。

自研客户端接订阅时,把「注入前缀 / 伪装 Claude Code / 清洗参数」三项都开着最稳——它们对合规请求是无操作。
